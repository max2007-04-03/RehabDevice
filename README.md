# 🏥 RehabDevice — Автономна медична ІоТ-система моніторингу реабілітації кисті (ESP32)

**RehabDevice** — це професійний автономний медико-інженерний IoT-комплекс на базі мікроконтролера **ESP32** та 6-осьового інерційного датчика **MPU6050 / MPU6500 (GY-521)**. Система призначена для точного відстеження рухомості суглобів кисті в реальному часі, автоматичного визначення плавности/тремору, збору розширеної клінічної аналітики, а також **гейміфікації процесу реабілітації**.

Весь користувацький веб-інтерфейс (UI), медичні показники, інтерактивні підказки, ігровий модуль та експортовані CSV-звіти працюють **виключно українською мовою** 🇺🇦 з урахуванням сучасної медичної термінології та клінічних вимог.

Пристрій є повністю незалежним від зовнішнього інтернету. Він створює власну Wi-Fi точку доступу (`RehabDevice_AP`) з підтримкою **Captive Portal** (автоматичне спливаюче вікно авторизації на iOS та Android). Історія тренувань надійно зберігається у повноцінній реляційній базі даних **SQLite на SD-карті**, з автоматичним резервуванням на вбудовану пам'ять (`LittleFS`) у разі відсутності картки.

---

## 🎮 1. Гейміфікація реабілітації (Ігровий модуль)

Система включає потужний модуль ігрової терапії, який перетворює нудне повторення медичних вправ на захопливий процес! Усі ігрові обчислення виконуються з частотою ~60 FPS завдяки безперебійному WebSocket-стрімінгу з мікроконтролера.

У системі доступні 3 ігри різної спрямованості:
1. **🎮 Пінг-понг (Smart Bot):** Гра на досягання крайніх кутів амплітуди. Розумний бот (Адаптивна складність) автоматично підлаштовує свою швидкість під поточні можливості пацієнта (його амплітуду та плавність).
2. **⚖️ Баланс-Борд (Рівновага):** Гра на розвиток дрібної моторики, контролю тремору та рівноваги. Пацієнт має утримувати дошку рівно, компенсуючи хвилі та пориви вітру своїм зап'ястям.
3. **🏎️ Car Dodge (Ухиляння):** Динамічна гра на швидкість реакції. Пацієнт керує машинкою, уникаючи перешкод, що вимагає швидких і точних рухів.

## 🛠 2. Апаратне підключення (Розпіновка)

Для складання пристрою використовується плата **ESP32 DevKit**, модуль гіроскопа **GY-521 (MPU-6050/6500)** та **MicroSD Card Adapter**.

### 2.1. Підключення гіроскопа (GY-521)

| Вивід датчика (GY-521) | Пін ESP32 | Опис призначення |
| :--- | :--- | :--- |
| **VCC** | **3V3** (3.3V) | Живлення датчика |
| **GND** | **GND** | Спільна земля |
| **SCL** | **GPIO 22** | Лінія тактування апаратної шини I2C |
| **SDA** | **GPIO 21** | Лінія даних апаратної шини I2C |
| **INT** | **GPIO 17** | Апаратне переривання готовності пакетів DMP |
| **AD0** | **GND** | Притягнути до землі для фіксації I2C-адреси `0x68` |

### 2.2. Підключення SD-карти (SPI)

| Вивід SD-модуля | Пін ESP32 | Опис призначення (VSPI) |
| :--- | :--- | :--- |
| **VCC** | **5V (VIN)** | Живлення модуля |
| **GND** | **GND** | Спільна земля |
| **MISO** | **GPIO 19** | Master In Slave Out |
| **MOSI** | **GPIO 23** | Master Out Slave In |
| **SCK** | **GPIO 18** | Serial Clock (такти шини) |
| **CS** | **GPIO 5** | Chip Select (вибір пристрою) |

> [!IMPORTANT]  
> **Стабільність живлення (Обов'язково!)**  
> При одночасній роботі Wi-Fi та записі на SD-карту можливі просадки напруги. Встановіть електролітичний конденсатор на **470 мкФ (10V-16V)** у шину живлення на макетній платі.

## 📂 3. Встановлення та налаштування (PlatformIO)

Проєкт використовує професійне середовище розробки **PlatformIO**, яке автоматично завантажить усі залежності (ArduinoJson v7, Sqlite3Esp32, ESPAsyncWebServer, MPU6050).

1. Встановіть **Visual Studio Code (VSCode)** та розширення **PlatformIO IDE**.
2. Відкрийте теку проєкту (`esp32dev-RehabDevice`) у VSCode.

---

## 🚀 4. Як прошити та запустити комплекс

У лівій панелі VSCode натисніть на іконку PlatformIO, розгорніть `Project Tasks -> esp32dev_RehabDevice`:

1. **Прошивка коду (C++):** Перейдіть у `General` і натисніть **Upload**.
2. **Прошивка веб-інтерфейсу (LittleFS):** 
   * Перейдіть у `Platform` і натисніть **Build Filesystem Image**.
   * Натисніть **Upload Filesystem Image** *(перед цим закрийте Serial Monitor!)*.
3. **Запуск:**
   * Підключіться з телефону/ПК до Wi-Fi **`RehabDevice_AP`** (пароль: **`rehab1234`**).
   * Відкриється вікно Captive Portal, або перейдіть вручну за адресою **`http://192.168.4.1`**.

## 🏗 5. Сучасна інженерна архітектура системи

Система використовує найсучасніші архітектурні рішення для стабільної роботи на мікроконтролері:

### 🔹 1. Підсистема сенсорики (`SensorMPU.cpp`)
* Використовує апаратний блок **DMP** (Digital Motion Processor) для отримання кутів (Pitch/Roll/Yaw) без завантаження ядра ESP32.
* Підтримує миттєве рекалібрування "на льоту" та інверсію осі.

### 🔹 2. Сховище даних на SQLite (`SDManager.cpp` & `DatabaseManager.cpp`)
* Надійне збереження тисяч сесій у базі **SQLite3** безпосередньо на SD-карті (`rehab.db`).
* Механізм **Smart Retry**: якщо під час руху пацієнта контакти карти тимчасово відходять, система здійснює до 3 повторних спроб запису з таймаутом, щоб не втратити дані.

### 🔹 3. Клінічний аналітичний рушій (`AnalyticsEngine.cpp`)
* **Амплітуда та Тремор:** Диференціювання прискорення для фіксації ривків (поріг `180.0 deg/s^2`).
* **Згинання (Flexions):** Подвійний гістерезис для ігнорування фізіологічного тремору.

### 🔹 4. Безпечний Networking (WebSocket + Pagination)
* **WebSocket-пагінація**: Передача великої історії пацієнтів відбувається чанками (по 50 записів) через єдине WebSocket-з'єднання. Це повністю захищає ESP32 від виснаження TCP-пулу (PCB exhaustion) та браку оперативної пам'яті (OOM/std::bad_alloc).

## 🖥 6. Можливості веб-інтерфейсу (Single Page Application)

* **Вкладка «Пацієнт (Тренування)»:**
  * Візуалізатор нахилу (інтерактивне коло).
  * 3 реабілітаційні гри.
  * Живі метрики сесії (кут, швидкість, плавність).
* **Вкладка «Кабінет Лікаря»:**
  * **Smart Search:** Пошук пацієнтів та резюме динаміки лікування.
  * **Автономні графіки:** Візуалізація прогресу без доступу до інтернету (Canvas API).
  * **CSV Експорт:** Завантаження всієї статистики у форматі Excel (`uFEFF` UTF-8 BOM).
  * **Розрахунок відновлення:** Оцінка у відсотках відносно цільової норми (напр. 90°).
